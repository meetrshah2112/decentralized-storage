How it works

Your file is sent to the local IPFS daemon. IPFS returns a unique CID. Django stores that CID so the file can be viewed or downloaded later.

CID Based Storage

Every uploaded file receives a content identifier. The same file will always produce the same CID, which is the core idea behind content-addressed decentralized storage.
